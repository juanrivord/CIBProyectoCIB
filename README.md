# Proyecto CIB — Juan Rivera Ordóñez

Portal web del módulo de **Ciberseguridad** (curso 2025-2026, I.E.S. Los Sauces). Reúne en una única página índice los trabajos y estudios realizados en cada unidad didáctica.

## Contenido

La página principal, [`indexProyectoCIB.php`](indexProyectoCIB.php), organiza el material por unidades:

| Unidad | Tema | Material |
|--------|------|----------|
| UD1 | Ciberseguridad | [Estudio tema 1 (PDF)](webroot/docs/EstudioTema1.pdf) |
| UD2 | Servidor web seguro | [Guía de instalación](https://github.com/juanrivord/JRODAWProyectoDAW/blob/main/docs/Guia_Instalacion_JRO_USED.md) |
| UD3 | Aplicación web segura | En preparación |
| UD4 | Infraestructura web segura | En preparación |

## Estructura

```
indexProyectoCIB.php   Página índice del proyecto
webroot/
├── css/               Hojas de estilo (indice.css)
├── docs/              Documentos y estudios en PDF
├── font/Roboto/       Tipografía Roboto
├── images/            Imágenes y capturas
└── script/            JavaScript
```

## Uso

Copia el proyecto en el directorio raíz de un servidor web con PHP (por ejemplo, Apache) y abre `indexProyectoCIB.php` en el navegador.
